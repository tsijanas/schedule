Teams & People

Create teams and set a manager for each, then add people, assign them to a team, and set which tasks they can work. This is the source of truth the scheduler reads from.

People

Standard tasks by level

What's normally open to each level on this team — the same setting each task's own Level picker uses in Tasks, just organized by level instead of by task, since that's usually the more useful direction to think in. New people start eligible for whatever's checked here for their level; every person's own Eligible Tasks stays individually editable afterward regardless of what's set here.

Tasks

The conditions each task runs under — who's allowed to do it, and whether it can't be combined with another task on the same day.

Available from other teams

Created by another team in this department. Adding one copies its rules (level restriction, exclusions, same-week setting) into this team's own tasks — it becomes independent from here, so editing it afterward only affects this team.

Requirement

How many people each task needs, per weekday. This is what the scheduler tries to fill.

Schedule

Who's on what, day by day — generated automatically, and balanced against how often everyone has already done each task.

The weekly loop, in short

Review what's here for the week — adjust if something's wrong (click any name directly for one swap, or use "Replace someone this week" if they need to come off everything) — Generate only if you want the algorithm to fill it in from scratch (it replaces the whole week, not just the gaps — there's a confirmation and an undo either way) — then Send notifications once you're happy, so people actually find out what changed.

Since this team's in a department: "Schedule" is just this one team. "Grand Schedule" combines every team in the department into one view — most day-to-day adjusting happens in the plain Schedule tab; Grand Schedule is for the department-wide picture and bulk actions across teams at once.

Combined view across every team in this department.

Set one department-wide total per task, per day — it splits across your teams automatically, proportional to each team's headcount. Matches tasks by name across teams, since each team's tasks aren't formally linked yet. Nothing changes on any team's own Requirement until you click Apply.

Set up a department

Groups several teams under one department, with a combined Grand Schedule and Grand Requirement. Create the department first, then add teams to it — nothing about any existing team is touched by creating a department itself.

Import team roster

Paste a roster sheet — name, level, team, email, then one column per task with a checked/unchecked value per person — and it sets up the teams, people, tasks, and per-person eligibility all at once. Include the header row; task names come from it. This only creates and updates data — it never deletes anyone or removes anyone's access, and it never sends invites (do that separately from Team & People once you're ready).
